NEXUS // STRIKE Website Specification (Claude Code Prompt) Website Brief · React / GSAP ScrollTrigger / Lenis

Master developer prompt instructing Claude Code to build NEXUS // STRIKE with React, GSAP ScrollTrigger, Lenis, and full-viewport media presentation across 4 pinned chapters.

Build a clean, premium, full-screen immersive gaming website called “NEXUS // STRIKE.”

Use React, Tailwind CSS, GSAP ScrollTrigger, and Lenis.

This is not a card-based or dashboard-style website. It is a cinematic scroll experience: every generated image and video is presented as a full-screen visual chapter, with minimal HTML text layered over it.

Use all provided media assets completely.

================================
IMPORTANT MEDIA RULES
================================
- Never place key media inside small cards, browser frames, device mockups, or boxed content panels.
- Every image and video must be displayed at large scale, occupying the full viewport or most of it.
- Do not crop important media. Use object-fit: contain when necessary so every asset remains fully visible.
- The empty area around contained 16:9 media must remain solid #0A0A12, making it feel intentional and immersive.
- Text is always HTML layered on top of the media, never embedded into media.
- Use subtle dark overlays only where required for readability; do not obscure the artwork.
- Use every generated asset in the visual sequence.

================================
VISUAL DESIGN
================================
- Background: #0A0A12 Deep Void Indigo.
- Surface overlays only: #161626, with very low opacity.
- Primary scroll/progress color: #00F0FF Electric Cyan.
- Secondary energy/accent color: #8B5CF6 Hyper Violet.
- No red, orange, green, gold, gradients, glassmorphism, excessive borders, or generic gaming dashboard elements.
- Use cinematic typography: massive condensed uppercase headlines, small technical labels, minimal body copy.
- Keep the page calm, spacious, refined, dark, and expensive.

================================
SCROLL SYSTEM
================================
- Build a sequence of full-screen pinned visual panels.
- Each panel uses the media as the main experience.
- Text overlays fade, move, and reveal based on scroll.
- Videos are scrubbed by scroll position, not autoplayed.
- Scrolling upward reverses every transition smoothly.
- On mobile, disable pinning and show a clean stacked vertical experience with static image fallbacks.
- Add a subtle fixed vertical progress indicator on the right using Electric Cyan.

- Deliver complete polished production-ready code with components, media handling, GSAP animation setup, ScrollTrigger logic, and responsive styling.
