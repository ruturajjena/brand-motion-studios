# Claude Code Prompt

## Role

You are an award-winning creative developer specializing in **Awwwards**, **FWA**, and **CSS Design Awards** websites.

Build a production-ready website for a premium interior design studio specializing in luxury kitchens.

This should feel comparable to websites from:

- Obys
- Active Theory
- Locomotive
- Dogstudio
- Resn
- MakeMePulse
- Apple
- Minimal Gallery

The experience must prioritize storytelling through scroll.

The supplied four videos are the primary storytelling assets.

Do **NOT** autoplay the videos.

The website should feel handcrafted, premium and cinematic.

# Video Usage

There are four videos.

These are NOT background videos.

Treat each video like a premium architectural exhibit.

Each video should remain paused.

Scroll controls playback.

As user scrolls:

Video progresses.

When user scrolls upward:

Video reverses.

Never autoplay.

Never loop.

Never continue playing.

The scroll position controls the video's currentTime.

Use GSAP ScrollTrigger.

Scrub the video.

Each frame should map to scroll position.

The user literally controls time.

This is extremely important.
