BR Industrial Hardware Showcase Website Spec Website Brief · Next.js / Framer Motion / Sticky Scroll

Master developer brief for Claude Code to build a Teenage Engineering & Nothing Tech inspired hardware showcase for BR. Built By Ruturaj.

You are acting as a Lead Creative Technologist and Senior Front-End Engineer specializing in high-end industrial design showcase websites (think Teenage Engineering, Apple, and Nothing Tech aesthetics).

Build a clean, ultra-minimalist, scroll-animated e-commerce/showcase web application for the hardware brand:
**BR. Built By Ruturaj (BR)** — A studio crafting precision-engineered mice, mechanical keyboards, and magnetic power banks.

---

### 1. 🛠️ Tech Stack & Requirements
- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS (utilizing CSS variables for industrial color palettes)
- **Animation Engine:** Framer Motion (for sticky scroll-reveals, smooth parallax, and micro-interactions) + Lucide React (minimalist iconography)
- **Fonts:** Geist / Inter paired with a technical monospaced font (e.g., JetBrains Mono / Geist Mono) for spec readouts.

---

### 2. 🎥 Asset Integration (Strictly 6 Videos)
Store these video paths under `/public/assets/videos/` and map them to their corresponding product components:

#### 🖱️ Category 1: Precision Mice
1. `mouse-exploded.mp4` -> **Video 1 (Exploded View Assembly):** 3D exploded motion reveal of minimalist wireless mouse expanding into floating precision layers (matte graphite shell, optical sensor, titanium wheel, PCB, battery).
2. `mouse-hero.mp4` -> **Video 2 (Hero Reveal & Desk Setup):** Cinematic camera pan across low-profile ergonomic wireless mouse sitting on dark felt mat with subtle ambient scroll wheel lighting.

#### ⌨️ Category 2: Mechanical Keyboards
3. `keyboard-exploded.mp4` -> **Video 3 (Exploded Mechanical Layers):** 3D exploded motion reveal of 75% custom keyboard floating against light-beige background (translucent caps, switches, brass plate, PCB, acoustic foam, anodized case).
4. `keyboard-macro.mp4` -> **Video 4 (Macro Switch Mechanics):** Macro close-up of tactile switches being pressed on frosted polycarbonate body with subtle warm-white backlighting.

#### 🔋 Category 3: Power Banks
5. `powerbank-exploded.mp4` -> **Video 5 (Exploded Power Architecture):** 100W USB-C magnetic power bank disassembling into CNC aluminum chassis, MagSafe coil, stacked polymer cells, OLED screen, and copper heat pads.
6. `powerbank-snap.mp4` -> **Video 6 (Magnetic Snap & Desktop Reveal):** Ultra-slim matte-black magnetic power bank floating down and snapping onto a smartphone with activating LED charge gauge.

---

### 3. 🎨 Design System & UI/UX Guidelines
- **Palette:**
  - Backgrounds: Obsidian Dark (`#0A0A0C`), Matte Graphite (`#121215`), Off-White Studio (`#F5F5F3`)
  - Accent: Raw Brass / Metallic Warm Slate (`#C8A97E`)
  - Typography: Pure White (`#FAFAFA`), Muted Gray (`#71717A`)
- **Layout Philosophy:** Architectural grid lines, sub-pixel borders, generous whitespace, stark typography contrast, sticky scroll viewports where products expand layer-by-layer as the user scrolls.

---

### 4. 📐 Website Structure & Key Sections

#### A. Global Navigation
- Fixed minimalist header with blur backdrop (`backdrop-blur-md`).
- Brand mark: **BR** logo with `Built By Ruturaj` subtitle in technical mono font.
- Dynamic indicator showing active section / scroll progress.

#### B. Hero Section
- High-impact layout featuring a dual-video background switcher or ambient preview.
- Headline: *"Monolithic Engineering. Tactile Perfection."*
- Interactive CTA with smooth scroll target.

#### C. Interactive Exploded Product Showcases (Sticky Scroll Reveal)
Create 3 distinct sticky scroll sections—one for each category:

1. **Mice Section (`#mice`):**
   - **Scroll Interaction:** As the user scrolls through the 200vh section, `mouse-exploded.mp4` plays/scrubs into view alongside an interactive component breakdown list (Shell, Optical Sensor, Titanium Wheel, Battery).
   - **Secondary Highlight:** Card featuring `mouse-hero.mp4` showcasing the tactile side buttons and desk aesthetics.

2. **Keyboard Section (`#keyboards`):**
   - **Scroll Interaction:** Sticky container featuring `keyboard-exploded.mp4` expanding vertically. Floating technical spec overlays trigger at key scroll thresholds (Gasket Mount, Hotswap Sockets, Brass Plate).
   - **Secondary Highlight:** Split-screen section with `keyboard-macro.mp4` demonstrating keypress bounce and LED illumination dynamics.

3. **Power Bank Section (`#powerbanks`):**
   - **Scroll Interaction:** `powerbank-exploded.mp4` animating open to reveal CNC Aluminum, OLED screen, and wireless MagSafe coils.
   - **Secondary Highlight:** Snappy interactive showcase featuring `powerbank-snap.mp4`.

#### D. Tech Specs Comparison Matrix
- Minimalist grid layout comparing key hardware specs (Weight, Materials, Connectivity, Battery Capacity, Processing Latency).

#### E. Footer
- Minimalist architectural footer with brand manifesto, newsletter signup with subtle button micro-animations, and copyright info.

---

### 5. 🚀 Execution Steps for Claude Code
1. Initialize a clean Next.js project structure with Tailwind CSS and Framer Motion.
2. Build reusable layout components (`Navbar`, `Footer`, `VideoPlayer`, `ExplodedCard`).
3. Construct the custom scroll-driven animation hooks (`useScroll`, `useTransform`) for sticky video-reveals.
4. Assemble all 3 product sections using the mapped 6 video assets.
5. Apply polished hover states, cursor interactions, and responsive design for all viewport sizes.
