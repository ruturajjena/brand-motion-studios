The Palace Website Specification (Claude Code Prompt) Website Brief · Next.js 16 / GSAP ScrollTrigger / Lenis

Master developer prompt instructing Claude Code to build an unforgettable 80-second scroll-driven destination film website with Next.js 16, GSAP ScrollTrigger, Lenis, dynamic frame luminance sampling, and Canela typography.

You are an award-winning Creative Director, Senior Product Designer, Motion Designer, and Principal Frontend Engineer.

Your work should feel comparable to websites from Active Theory, Resn, Locomotive, Basic Agency, Apple, Dogstudio, and Awwwards Site of the Day winners.

The objective is NOT to build a hotel website.
The objective is to create an unforgettable cinematic digital experience where scrolling controls an 80-second luxury film.

This website should feel like an interactive movie where every pixel communicates luxury through restraint.

==================================================
1. TECH STACK
==================================================
• Next.js 16 (App Router)
• React 19
• TypeScript
• TailwindCSS v4
• GSAP 3 & GSAP ScrollTrigger
• Lenis smooth scrolling
• Framer Motion
• SVG Morph animations & CSS Variables
• Dynamic viewport units
• requestAnimationFrame optimization

NO Bootstrap, NO jQuery, NO component libraries. Everything custom.

==================================================
2. DESIGN PHILOSOPHY & PALETTE
==================================================
- Think like an Art Director, not a frontend developer.
- Atmosphere: Luxury fashion campaign, minimal UI, massive visual impact, elegant whitespace.
- Color System: Near-black (#060608), warm ivory (#F9F8F5), soft champagne (#EFE7DA), subtle gold accents (#D4AF37), glass reflections. Absolutely no bright saturated colors.
- Dynamic Frame Lighting: Sample video frame average brightness — UI subtly warms up during golden hour and darkens during blue hour/night scenes.
- Typography: Luxury serif for headlines (Canela / PP Editorial / Playfair Display) paired with modern sans for UI (Neue Montreal / Inter / Geist).

==================================================
3. VIDEO PLAYBACK ARCHITECTURE & SCROLL SYSTEM
==================================================
- Virtual scroll height: 9000–12000px.
- Single sticky fullscreen canvas/video container where `video.currentTime` is strictly mapped to `ScrollTrigger.progress` via requestAnimationFrame with smooth inertial lerp damping.
- No autoplay, no independent playback controls, no audio. Scroll IS playback.
- Scrolling forward flies through the palace; scrolling backward smoothly reverses the drone trajectory.

==================================================

==================================================

==================================================
5. UI COMPONENTS & MICRO-INTERACTIONS
==================================================
- Transparent Floating Navbar: Blurred glass header that auto-hides on downward scroll and smoothly re-appears on upward scroll.
- Preloader: Deep black screen with elegant typography, video metadata preloading, and smooth transition into frame 1.
- Custom Cursor: Trailing magnetic ring cursor with gentle repulsion over buttons and subtle text tracking.
- Performance: 60 FPS GPU-accelerated transforms, zero layout shifts, lazy loading, and responsive desktop/tablet/mobile layouts.

Deliver a production-quality, clean TypeScript codebase ready to run locally via `npm run dev`.
