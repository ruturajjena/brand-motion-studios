AI Presentation Deck — NotebookLM & Antigravity

A 3-step workflow to extract structured presentation content from research sources using NotebookLM in Gemini, then convert it into an Apple-quality visual deck with Antigravity.

Step 1 — Create NotebookLM & Ingest Sources Setup Step 1 · NotebookLM / Gemini

Prepare your source material inside Google Gemini / NotebookLM before generating the structured slide outline.

Prerequisite Setup:
Create a new NotebookLM notebook inside Google Gemini, upload your research documents/PDFs, and add direct links to all your reference sources.

Step 2 — NotebookLM Slide Content Generator Prompt Prompt Step 2 · Gemini / NotebookLM

Copy and paste this prompt into NotebookLM / Gemini to analyze your uploaded sources and generate structured slide outlines with visual recommendations, speaker notes, and smooth transitions.

You are an expert educator, instructional designer, and presentation consultant.

Analyze all the uploaded sources and create content for slides 

Requirements:

- Generate a complete slide deck in a logical sequence.
- Keep each slide focused on one key concept.
- Use concise, presentation-friendly language instead of long paragraphs.
- Include a clear title for every slide.
- Structure the content using bullet points.
- Highlight important keywords in **bold**.
- Explain complex topics in a simple, easy-to-understand manner.
- Maintain a consistent flow from introduction to conclusion.
- Avoid unnecessary repetition.

For every slide, follow this format exactly:

---
Slide X: [Title]

Objective:
(1 sentence explaining the purpose of the slide)

Content:
• Bullet point 1
• Bullet point 2
• Bullet point 3
• Bullet point 4
• Bullet point 5

Visual Recommendation:
(Describe the ideal visual that should appear on this slide. Examples:
- Flowchart
- Process diagram
- Timeline
- Mind map
- Comparison table
- Architecture diagram
- Cycle diagram
- Anatomy illustration
- Infographic
- Decision tree
- Funnel
- Network diagram)

Speaker Notes:
(2–4 sentences expanding on the bullets for the presenter.)

Transition:
(One sentence connecting this slide naturally to the next slide.)
---

Additional Instructions:

- If the topic contains processes, automatically generate flowchart recommendations.
- If comparisons exist, recommend comparison tables.
- If anatomy or technical concepts exist, recommend labeled diagrams.
- If data is available, recommend charts instead of text.
- If relationships exist, recommend mind maps or architecture diagrams.
- Break large topics into multiple slides instead of overcrowding one slide.
- Generate enough slides to comprehensively cover the topic.
- End with:
  - Key Takeaways
  - Summary
  - References (derived from the uploaded sources)

Output only the slide content in the specified format. Do not include any explanations or markdown.
Step 3 — Antigravity Presentation Design Prompt Prompt Step 3 · Antigravity / Nano Banana

Paste your generated slide content along with this prompt into Antigravity to convert the outline into an Apple / Linear / Stripe inspired visual presentation with automatic Nano Banana diagram generation.

You are an award-winning presentation designer, infographic artist, and visual storyteller.

Your task is to convert the provided slide content into a premium presentation. Do NOT simply place text on slides. Design every slide so it looks like it was created by a professional presentation agency.

## Overall Style

- Modern, minimal, premium
- White background with subtle gradients
- Clean spacing
- Large typography
- Glassmorphism where appropriate
- Apple / Linear / Stripe inspired design
- Professional illustrations instead of stock photos
- Consistent color palette throughout
- Soft shadows and rounded corners
- Plenty of whitespace
- 16:9 presentation

## Slide Layout

For every slide:

- Create a strong visual hierarchy.
- Keep text concise.
- Use icons wherever possible.
- Convert lists into visual elements.
- Animate elements sequentially where appropriate.
- Use premium transitions.

## Image Generation

Whenever an image or illustration is needed, automatically generate it using Nano Banana.

Never use generic stock images.

Generate original visuals matching the topic.

Examples include:

• Detailed labeled diagrams
• Technical architecture illustrations
• Medical illustrations
• Scientific diagrams
• Process flow diagrams
• Infographics
• Mind maps
• Network diagrams
• Timelines
• Comparison graphics
• Exploded views
• Cross-section illustrations
• Isometric illustrations
• Data visualizations
• Device mockups
• UI illustrations
• Workflow graphics

All generated visuals should:

- Match the slide color palette
- Be vector-like
- High resolution
- Minimal
- Easy to understand
- Presentation-ready
- Include labels where necessary

## Automatic Diagram Rules

If the content describes:

Process
→ Generate a professional flowchart.

Lifecycle
→ Generate a circular cycle diagram.

Timeline
→ Generate a horizontal timeline.

Comparison
→ Generate a side-by-side comparison infographic.

Statistics
→ Generate beautiful charts.

Hierarchy
→ Generate an organization tree.

System
→ Generate an architecture diagram.

Medical topic
→ Generate accurate anatomical illustrations with labels.

Engineering topic
→ Generate exploded technical diagrams.

Programming topic
→ Generate architecture diagrams, API flow diagrams, and data pipelines.

Business topic
→ Generate modern business infographics.

AI topic
→ Generate neural network style illustrations and workflow diagrams.

Cloud topic
→ Generate AWS/Azure/GCP architecture diagrams.

## Text Handling

Never overcrowd slides.

Split large slides into multiple slides.

Maximum:
- 6 bullets
- 12 words per bullet

Highlight important keywords.

## Visual Quality

Every slide should look like it belongs in an Apple Keynote presentation.

No clipart.

No emojis.

No pixelated graphics.

Every generated image should be unique and specifically created for the slide.

## Icons

Use modern outlined icons.

Maintain consistency throughout the presentation.

## Animations

Apply subtle professional animations.

Fade
Move Up
Scale
Morph
Progressive Reveal

Animate diagrams piece by piece.

## Final Slides

Generate:

- Cover Slide
- Agenda
- Content Slides
- Key Takeaways
- Summary
- Thank You

The final presentation should be client-ready, visually stunning, and require no manual edits.
