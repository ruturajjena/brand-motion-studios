# GLOBAL ANIMATION RULES

-   Use Lenis smooth scrolling.
-   Every animation uses GSAP + ScrollTrigger.
-   Every section has motion.
-   Mouse movement adds subtle parallax.
-   No autoplay anywhere.
-   All videos are scrubbed by scroll.
-   Scrolling backwards reverses animations perfectly.

## Video Control System

Treat videos as interactive timelines, never background videos.

Requirements:

-   preload="metadata"
-   pause all videos immediately
-   disable autoplay
-   disable looping
-   map ScrollTrigger progress to currentTime
-   use requestAnimationFrame for smooth updates
-   scrolling upward reverses the animation

The experience should feel like rotating a 3D object with the mouse
wheel.
