Inside Intelligence — AI Robot Landing Page Spec Website Brief · Next.js + GSAP

A comprehensive developer brief for building "Inside Intelligence", a 60FPS scroll-controlled interactive AI robot anatomy landing page using Next.js, GSAP ScrollTrigger, and Lenis.

# PROJECT

Create a cinematic futuristic landing page called

"Inside Intelligence"

The entire experience should feel like opening the mind of an AI robot.

The page should be built using

- Next.js
- TailwindCSS
- GSAP
- ScrollTrigger
- Lenis Smooth Scroll

The experience must run at 60FPS.

Everything should feel premium.

No clutter.

No gradients everywhere.

No neon overload.

Think Apple Event meets OpenAI meets sci-fi movie.

---

# CORE IDEA

The user scrolls through the anatomy of an AI.

The robot slowly reveals itself.

Every scroll progresses the story.

Scrolling back perfectly reverses every animation.

Nothing should simply fade.

Everything should move physically.

---

# VIDEOS AVAILABLE in this folder

BodyExplode.mp4

Robot standing normally.

As the video progresses the body explodes revealing internal components.

HeadExplode.mp4

Robot head moves left.

Then explodes revealing camera, processor, circuits and glowing cables.

---

# VERY IMPORTANT

Do NOT autoplay these videos.

Instead use them as scroll-controlled animations.

The video's currentTime must be directly linked to ScrollTrigger progress.

Example

Scroll top

video.currentTime = 0

Middle

video.currentTime = 50%

Bottom

video.currentTime = duration

Scrolling upward should rewind perfectly.

No looping.

No play button.

No controls.

The visitor should feel like THEY are operating the robot.
