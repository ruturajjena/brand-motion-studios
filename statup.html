CONTINUOUS FPV DRONE PROMPTS — BR–BrandMotion Headquarters (48 Seconds)

Global Instructions (Include at the beginning of EVERY prompt):
```text
CONTINUATION SHOT.
This clip must begin exactly where the previous clip ended. Maintain identical camera velocity, heading, altitude, lighting, weather, cloud density, lens characteristics, exposure, color grading, and cinematic style.
No jump cuts. No scene resets. No teleporting. No time skip. No sudden acceleration or deceleration.
The camera movement must feel like one uninterrupted premium aerial FPV cinematic shot.
Ultra realistic. Large-scale architecture. Natural camera inertia. Soft cinematic motion blur. HDR. Global illumination. Ray traced reflections. Volumetric clouds. 8K photorealism. Luxury Apple keynote quality.
```

BR–BrandMotion Website Specification (Claude Code Prompt) Website Brief · Next.js 15 / GSAP ScrollTrigger / Lenis

Master developer prompt instructing Claude Code to build BR–BrandMotion with Next.js 15, GSAP ScrollTrigger, Lenis, 6 pinned scroll-scrubbed video sections, liquid magnetic buttons, and Awwwards SOTD polish.

You are an Awwwards Site of the Day winning Creative Director, Senior Motion Designer and Principal Frontend Engineer.

Your task is to build a world-class cinematic storytelling website for

BR–BrandMotion

This is NOT a normal landing page. This is an immersive scroll-driven experience where the entire website is synchronized with six cinematic videos. The website should feel like the user is flying through one continuous journey (Apple Event meets Nothing.tech, Active Theory, Locomotive, and Dogstudio).

==================================================
1. TECH STACK & DEPENDENCIES
==================================================
• Next.js 15 (App Router, React 19)
• TypeScript
• Tailwind CSS
• GSAP 3 & GSAP ScrollTrigger
• Lenis Smooth Scroll
• Framer Motion (where appropriate)
• Shadcn UI
• Motion One
• 60 FPS GPU-accelerated transforms, zero layout shifts.

==================================================
2. VIDEO ASSETS & CONTINUOUS SCRUB ENGINE
==================================================
Videos located in `/public/videos/`:
- `video-1.mp4` (Clouds & Logo)
- `video-2.mp4` (Headquarters Reveal)
- `video-3.mp4` (Entering the Office)
- `video-4.mp4` (Collaborative Workspace)
- `video-5.mp4` (Innovation Lab & Studios)
- `video-6.mp4` (Exit to Nature & Hero Loop)

Treat all six videos as ONE continuous movie.
- Browser scroll scrubs videos frame-by-frame via GSAP ScrollTrigger.
- Scrolling down advances the journey; scrolling upward reverses smoothly.
- Intelligent preloading: zero black, white, or buffering flashes between clips.
- Full viewport pinned presentation (`100vh`).
