F1 Motorsport Website Build Spec Website Brief · React 19 + GSAP

Complete specification instructing AI coding agents to build a Swiss editorial / Apple / Audi Motorsport inspired scroll-scrubbed F1 documentary site using React 19, Vite, Tailwind CSS v4, GSAP, and Lenis.

You are an award-winning creative developer and Awwwards-winning frontend engineer. All the videos are under assets folder. 

Build an immersive Formula 1 storytelling website inspired by Swiss editorial design, Apple product pages, Porsche configurator experiences and Audi Motorsport.

This is NOT a traditional landing page.

The entire experience is a cinematic, scroll-driven documentary where the user assembles and explores a Formula 1 car. Generate any required image using nano-banana if needed.

# GLOBAL ANIMATION RULES

- Use Lenis smooth scrolling.
- Every animation uses GSAP + ScrollTrigger.
- Every section has motion.
- Mouse movement adds subtle parallax.
- No autoplay anywhere.
- All videos are scrubbed by scroll.
- Scrolling backwards reverses animations perfectly.

## Video Control System

Treat videos as interactive timelines, never background videos.

Requirements:

- preload="metadata"
- pause all videos immediately
- disable autoplay
- disable looping
- map ScrollTrigger progress to currentTime
- use requestAnimationFrame for smooth updates
- scrolling upward reverses the animation

The experience should feel like rotating a 3D object with the mouse wheel.
